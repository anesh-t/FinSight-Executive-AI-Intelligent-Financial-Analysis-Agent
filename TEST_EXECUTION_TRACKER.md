## 🎯 Testing Tips

### For Structured Queries:

1. **Check SQL Execution:**
   - Look for SQL in terminal logs
   - Verify correct template selected
   - Check parameters are correct

2. **Verify Data:**
   - Numbers should match database
   - Formatting should be clean ($XXB, XX.X%)
   - Citations should be present

3. **Test Variations:**
   - Try different companies
   - Try different time periods
   - Try different phrasings

---

### For Unstructured Queries:

1. **Check Document Retrieval:**
   - Verify relevant documents found
   - Check chunk relevance
   - Look for retrieval scores

2. **Verify Answer Quality:**
   - Response should be coherent
   - Information should be accurate
   - No hallucinations

3. **Check Citations:**
   - Document name cited
   - Section/page referenced
   - Quotes included (when relevant)
